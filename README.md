# 오늘의 발표자 — AI 얼굴 인식 학생 추첨 웹앱

전자칠판 카메라(또는 외장 웹캠)로 교실을 비추면 학생 얼굴을 실시간으로 인식하고,
지정한 인원만큼 무작위로 발표자를 뽑아주는 웹앱입니다. 서버 없이 브라우저에서만 동작하며,
GitHub Pages로 바로 배포할 수 있습니다.

## 1. 주요 기능 및 정밀 인식 시스템

| 기능 | 설명 |
|---|---|
| **정밀 좌표계 1:1 정합** | `object-fit: contain` 기반 비디오 표시 영역과 캔버스 버퍼 해상도를 완벽히 일치시켜 허공 박스 발생을 원천 차단 |
| **얼굴 키포인트 기하 검증** | MediaPipe의 4개 필수 랜드마크(양쪽 눈, 코, 입)가 박스 내에 실제로 존재하는지 검증하여 사물·옷 패턴 오탐지 제거 |
| **연속 3프레임 확정 시스템** | 1~2프레임 찰나의 노이즈는 무시하고, 연속 3프레임 이상 탐지된 박스만 "확정 얼굴"로 승격 및 번호 배지 부여 |
| **잔상 방지 트래킹 & NMS** | IoU 0.4 기반 NMS로 중복 박스 병합, 지수평활(0.4:0.6) 위치 보정, 트래킹 실패 시 6프레임(약 0.1~0.2초) 내 즉시 소멸 |
| **AI 멀티 타일 확대 스캔** | 원거리·뒷자리 학생을 위해 화면을 2×2 / 3×2 타일로 분할 확대 탐지 (`runningMode: "IMAGE"` 기반) |
| **탐지 전용 밝기/대비 전처리** | 저조도·역광 환경을 위해 화면 비디오는 그대로 두고 탐지 전용 버퍼에만 `brightness(1.2) contrast(1.15)` 적용 |
| **화면 터치 강제 등록/삭제** | 전자칠판 터치스크린 완벽 대응! 미인식 학생 자리를 직접 터치하면 강제 등록되고, 오탐지 박스는 탭하여 즉시 삭제 |
| **➕ 30명 자동 채우기** | 현재 AI가 인식한 학생들을 보존하면서 빈 책상 슬롯을 자동 계산해 1초 만에 30명 완성 |
| **🏫 30명 좌석 일괄 배치** | 교실 5행×6열 책상 배열로 30개 자리를 원근감(앞자리 확대, 뒷자리 축소)을 반영해 한 번에 생성 |
| **📌 위치 고정 (잠금)** | 학생들의 움직임이나 딴청에도 박스와 번호가 흔들리지 않도록 위치를 완벽 고정 |
| **↔️ 좌우 반전 토글** | 전자칠판 전면 카메라 사용 시 실제 교실 좌석 방향과 화면 좌우를 일치시키는 미러 모드 전환 |
| **추첨 스냅샷 고정** | 추첨 시작 순간 확정 얼굴 목록을 스냅샷으로 고정해 추첨 도중 박스 변동 영향 원천 차단 |

## 2. 파일 구조

```
student-picker/
├── index.html   # HTML, CSS, JavaScript(ES Module)가 모두 포함된 단일 파일 (배포용)
├── README.md    # 프로젝트 설명 문서
└── .gitignore   # Git 제외 파일 설정
```

별도의 백엔드나 데이터베이스, 빌드 도구 없이 `index.html` 단일 파일만으로 브라우저에서 100% 동작합니다.
MediaPipe 모델 파일은 Google이 호스팅하는 CDN에서 최초 실행 시 자동으로 내려받습니다
(인터넷 연결 필요, 이후 브라우저 캐시로 재사용).

## 3. 전체 코드

`index.html`, `style.css`, `app.js` 세 파일이 이 대화의 첨부 파일로 함께 제공됩니다.
세 파일을 같은 폴더에 두면 바로 동작합니다.

## 4. 배포 방법 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다 (예: `student-picker`). Public으로 설정합니다.
2. 저장소에 `index.html`, `style.css`, `app.js` 세 파일을 업로드합니다.
   (저장소 메인 페이지 → **Add file → Upload files** 로 세 파일을 한 번에 드래그해도 됩니다.)
3. 저장소 상단 **Settings → Pages** 로 이동합니다.
4. **Build and deployment → Source** 에서 `Deploy from a branch` 를 선택합니다.
5. **Branch** 를 `main` (또는 기본 브랜치), 폴더는 `/ (root)` 로 선택 후 **Save** 를 누릅니다.
6. 1~2분 후 같은 화면 상단에 `https://<사용자아이디>.github.io/student-picker/` 형태의 주소가 표시됩니다.
   이 주소를 전자칠판 브라우저에서 열면 됩니다.
7. 접속 시 브라우저가 카메라 권한을 물으면 **허용**을 눌러야 합니다.
   (GitHub Pages는 기본적으로 HTTPS이므로 카메라 API가 정상 동작합니다.)

### 참고: 코드를 수정하고 싶을 때
파일을 로컬에서 수정한 뒤 같은 방법으로 다시 업로드(또는 git push)하면
GitHub Pages가 자동으로 새 버전을 반영합니다. 별도의 빌드 과정이 없습니다.

## 5. 개인정보 관련 안내

이 앱은 얼굴 이미지나 인식 결과를 서버로 전송하거나 저장하지 않습니다.
모든 얼굴 인식은 사용자의 브라우저 안에서만 실시간으로 처리되고, 화면을 벗어나는 순간 사라집니다.
다만 학생 얼굴이 화면에 표시되는 특성상, 학교의 초상권/개인정보 관련 지침에 따라
사전 안내 또는 동의 절차를 거치는 것을 권장합니다.
